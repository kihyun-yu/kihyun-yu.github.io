# Editable Site Data

Update these files when you want to change site content:

- `website.config.ts`: name, email, metadata, navigation, visible homepage sections, font style
- `home/About.mdx`: short bio/about text
- `home/education.ts`: education entries
- `home/experience.ts`: research and work experience entries
- `home/teaching.ts`: teaching experience entries
- `home/academic-services.ts`: reviewer/service entries
- `home/honors.ts`: honors and awards
- `publications/Publications.bib`: publication list in BibTeX format
- `assets/profile.jpg`: profile photo

The CV is intentionally kept outside this directory at the repo root: `cv.pdf`.
